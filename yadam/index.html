Yadam-Shorts-Automation

유튜브 채널 야담 한 폭의 운영자가 자신의 채널을 운영하기 위해 만든 내부 도구입니다. 이 도구는 YouTube API 서비스를 사용합니다. 운영자의 개인 서버에서만 실행되고 운영자 본인만 사용하며, 다른 사람은 로그인하거나 이용할 수 없습니다.

하는 일

  • 운영자가 직접 만든 영상을 운영자 채널에 올리고 공개 시각을 예약합니다. 제목, 설명, 태그와 '아동용 아님' 설정을 함께 넣습니다.
  • 이야기 유형별 재생목록을 만들고 영상을 추가합니다.
  • 채널 설명과 키워드를 관리합니다.
  • 주 1회 운영자 채널 영상의 통계를 운영자에게 보냅니다.

영상이 공개되기 전에 운영자는 알림을 받으며, YouTube Studio에서 공개 예약을 취소할 수 있습니다.

English

Yadam-Shorts-Automation is an internal tool built by the operator of the YouTube channel Yadam Hanpok to run that channel. The tool uses YouTube API Services. It runs only on the operator's private server and is used only by the operator; no one else can sign in to or use it.

What it does

  • Uploads the operator's own videos to the operator's channel and schedules their publication, with title, description, tags and "not made for kids".
  • Creates playlists by story type and adds the videos to them.
  • Keeps the channel description and keywords up to date.
  • Sends the operator a weekly message with the channel's video statistics.

Before a video goes public, the operator is notified and can cancel the scheduled publication in YouTube Studio.
