개인정보처리방침

Enjoy OnePage(이하 "사이트")는 이용자의 개인정보를 중요시하며 관련 법령을 준수합니다.

1. 개인정보의 수집

본 사이트의 계산기·도구는 모든 입력값을 이용자의 브라우저 내에서만 처리하며, 입력한 데이터를 서버로 전송하거나 저장하지 않습니다.

2. 쿠키 및 광고

본 사이트는 Google AdSense를 통해 광고를 게재합니다. Google을 포함한 제3자 공급업체는 쿠키를 사용하여 이용자의 이전 방문 기록을 바탕으로 광고를 게재할 수 있습니다. 이용자는 Google 광고 설정에서 맞춤 광고를 비활성화할 수 있습니다.

3. 로그 및 분석

서비스 개선을 위해 접속 통계가 익명으로 수집될 수 있으며, 개인을 식별하는 용도로 사용되지 않습니다.

4. 문의

개인정보 관련 문의는 사이트 운영자에게 전달해 주시기 바랍니다.

5. 유튜브 채널 운영 도구 (Yadam-Shorts-Automation)

운영자는 자신의 유튜브 채널 야담 한 폭을 운영하기 위해 내부 도구 Yadam-Shorts-Automation을 사용합니다. 이 도구는 YouTube API 서비스를 사용하며, 운영자의 개인 서버에서만 실행되고 운영자 본인만 사용합니다. 다른 사람은 이 도구에 로그인하거나 이용할 수 없습니다.

이 도구가 YouTube API 서비스를 통해 처리하는 정보에는 Google 개인정보처리방침도 적용됩니다. 이 도구를 사용하는 사람은 YouTube 서비스 약관에 동의하는 것입니다.

이용하는 정보

운영자가 Google 계정 로그인으로 허용한, 운영자 본인 채널의 정보만 이용합니다.

  • 채널 ID, 채널 이름, 채널 설명과 키워드
  • 운영자가 올린 영상의 ID, 제목, 설명, 태그, 공개 상태와 공개 예약 시각
  • 운영자 채널의 재생목록 ID와 이름
  • 운영자 채널 영상의 통계(조회수, 시청 시간, 평균 시청 시간, 구독자 증감)

다른 사용자나 다른 채널의 정보는 수집하지 않습니다. Google 계정 비밀번호는 받거나 저장하지 않으며, 이 도구는 쿠키를 사용하지 않습니다.

이용 목적과 공유

  • 운영자가 만든 영상을 운영자 채널에 올리고 공개 시각을 예약합니다.
  • 이야기 유형별 재생목록과 채널 설명을 관리합니다.
  • 주 1회 운영자 채널 영상의 통계를 운영자에게 보냅니다.

위 목적 외에는 사용하지 않으며, 광고나 판매에 쓰거나 제3자에게 제공하지 않습니다. 운영자에게 보내는 알림은 텔레그램 메신저로 전달되며, 알림에는 영상 제목, 공개 시각, 영상 링크와 통계만 담깁니다.

보관과 삭제

  • 로그인 토큰은 운영자 서버의 접근이 제한된 파일에만 저장하며, 도구를 사용하는 동안만 보관합니다.
  • 영상 ID와 공개 예약 정보는 영상이 공개되고 30일이 지나기 전에 삭제합니다. 재생목록 정보는 30일이 지나기 전에 YouTube에서 다시 받아 최신 상태로 맞춥니다.
  • 통계는 운영자에게 보낼 때만 받아 오며, 서버에 저장하지 않습니다.
  • 도구의 접근 권한이 유효한지 매주 확인하며, 권한이 해제되면 저장된 YouTube 관련 정보를 7일 안에 모두 삭제합니다.
  • 저장된 정보의 삭제를 요청하시면 7일 안에 삭제합니다. 이 도구에 저장된 정보를 삭제해도 YouTube에 올라간 영상이나 채널 정보는 삭제되지 않으며, 그 정보는 YouTube Studio에서 삭제해야 합니다.

접근 권한 해제

Google 보안 설정의 타사 앱 액세스 페이지에서 언제든 이 도구의 접근 권한을 해제할 수 있습니다. 해제하면 위에 적은 대로 저장된 정보를 삭제합니다.

English: YouTube channel tool (Yadam-Shorts-Automation)

The site operator uses an internal tool, Yadam-Shorts-Automation, to run the operator's own YouTube channel Yadam Hanpok. The tool uses YouTube API Services. It runs only on the operator's private server and is used only by the operator; no one else can sign in to or use it.

Information processed by the tool through YouTube API Services is also subject to the Google Privacy Policy. By using the tool, users agree to be bound by the YouTube Terms of Service.

Information used. Only information about the operator's own channel that the operator authorized through Google sign-in: the channel ID, name, description and keywords; the ID, title, description, tags, privacy status and scheduled publish time of videos the operator uploads; the IDs and names of the channel's playlists; and statistics for the channel's videos (views, watch time, average view duration, subscribers gained and lost). The tool does not collect information about other users or other channels, never receives or stores Google account passwords, and does not use cookies.

How it is used and shared. To upload the operator's own videos to the operator's channel and schedule their publication, to manage playlists by story type and the channel description, and to send the operator a weekly message with the channel's video statistics. The information is not used for any other purpose, not used for advertising or sold, and not shared with third parties. Notifications to the operator are delivered through the Telegram messenger and contain only video titles, publish times, video links and statistics.

Storage and deletion. The sign-in token is stored only in an access-restricted file on the operator's server and is kept only while the tool is in use. Video IDs and publishing schedules are deleted before 30 days have passed since the video was published. Playlist information is refreshed from YouTube before it is 30 days old. Statistics are fetched only when the weekly message is sent and are not stored on the server. The tool checks every week that its access is still valid; if access is revoked, all stored YouTube-related information is deleted within 7 days. Stored information is also deleted within 7 days on request. Deleting information stored by the tool does not delete videos or channel information on YouTube; that must be done in YouTube Studio.

Revoking access. Access can be revoked at any time on the Google security settings page. After revocation, stored information is deleted as described above.
