이용약관

1. 서비스 목적

Enjoy OnePage는 세금·금융·부동산 계산기 및 각종 생활 유틸리티 웹앱을 무료로 제공합니다.

2. 면책 조항

본 사이트의 모든 계산 결과와 정보는 참고용 추정치이며, 실제 세무·법률·금융 결정에 대한 책임은 이용자 본인에게 있습니다. 본 사이트는 제공된 정보의 정확성이나 이를 근거로 한 결정의 결과에 대해 법적 책임을 지지 않습니다.

3. 저작권

본 사이트의 콘텐츠 및 도구에 대한 권리는 운영자에게 있습니다.

4. 약관의 변경

본 약관은 필요 시 변경될 수 있으며, 변경 사항은 본 페이지에 게시됩니다.

5. 유튜브 채널 운영 도구 (Yadam-Shorts-Automation)

Yadam-Shorts-Automation은 운영자가 자신의 유튜브 채널 야담 한 폭을 운영하기 위해 사용하는 내부 도구이며, YouTube API 서비스를 사용합니다. 이 도구를 사용하는 사람은 YouTube 서비스 약관에 동의하고 그 약관을 따라야 합니다. 이 도구의 개인정보 처리는 개인정보처리방침 5항을 따릅니다.

English. Yadam-Shorts-Automation is an internal tool that the site operator uses to run the operator's own YouTube channel, and it uses YouTube API Services. By using this tool, users agree to be bound by the YouTube Terms of Service. Its handling of personal information is described in section 5 of the Privacy Policy.
